# 📚 JS-Info – JavaScript Study Notes

A structured self-study project based on the [javascript.info](https://javascript.info) book series.  
Each lesson is broken down into 7 files for deep understanding, quick review, and interview preparation.

---

## 🗂️ File Structure (Per Lesson)

| File | Content |
|------|---------|
| `01-explanation.md` | Full detailed explanation in Egyptian Arabic |
| `02-summary.md` | Quick review summary |
| `03-questions.md` | Questions (easy → hard) |
| `04-answers.md` | Full answers with reasons |
| `05-advanced.md` | Advanced challenges with answers |
| `06-interview.md` | English interview questions + answers |
| `07-notes.md` | Pro tips, real-world usage, and resources |

---

## 📖 Books Covered

### Part 1 – The JavaScript Language
> Core JavaScript concepts from basics to advanced

### Part 2 – Browser: Document, Events, Interfaces
> DOM manipulation, events, and browser APIs

### Part 3 – Additional Articles
> Extra topics like animation, regular expressions, and more

1. Read the lesson on [javascript.info](https://javascript.info)
2. Write detailed notes in Arabic (Egyptian dialect)
3. Solve all questions and challenges
4. Review interview questions in English
